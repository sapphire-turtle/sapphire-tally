# sapphire-tally-server

The app server of [sapphire-tally](https://github.com/sapphire-turtle/sapphire-tally):
the one process that reads and writes the tally's activities and stamps, syncs them
through the host's `sapphire-bridge`, and answers the tally's methods and MCP tools.

It is a library, run as `sapphire-tally serve` by either edition
([`sapphire-tally-headless`](../../headless/README.md) or the desktop app).
