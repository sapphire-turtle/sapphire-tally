# sapphire-tally-cli

The command line of [sapphire-tally](https://github.com/sapphire-turtle/sapphire-tally)'s
two editions: sapphire-framework's commands (`serve`, `status`, `service`, `workspace`,
`mcp`, …), which run the app server and the MCP server or call them, as a library.

To install the command, see [`sapphire-tally-headless`](../../headless/README.md) (no GUI)
or the desktop app; both put `sapphire-tally` on PATH.
